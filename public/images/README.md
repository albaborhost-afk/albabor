# Watermark logo for listing images

Place your **Albabor logo** here as `watermark.png` to have it applied as a semi-transparent watermark on all listing photos (boats, jetskis, engines, parts).

- **Filename:** `watermark.png`
- **Format:** PNG (with transparency recommended)
- **Recommended size:** about 300–400 px wide

If this file is missing, listing images are stored without a watermark. You can configure path and opacity in `config/listings.php` or via env: `LISTING_WATERMARK_PATH`, `LISTING_WATERMARK_OPACITY`.
